一套全开源的数字文创发行平台源码，前端基于 Uniapp 跨端框架开发，可编译为微信小程序、H5 等多端，覆盖藏品发售、盲盒玩法、碎片合成、藏品转增、创作者入驻等核心业务，代码无加密限制，支持自主阅读、修改、二次开发，适合文创机构、数字艺术团队搭建自有文创发行平台。

依托 Uniapp 的跨端特性，用户无需下载 APP，通过小程序或者 H5 链接即可进入平台。用户端支持藏品浏览、高清图文与视频展示、预约抽签、限时抢购、盲盒开启、碎片合成、个人藏品仓库、订单查询、收藏关注等功能。藏品详情页清晰展示创作简介、发行数量、版权信息、发售规则，发售前支持预约提醒，中签、流转、订单变更等消息可及时推送，适配藏品平台的发售运营节奏。

平台内置行业主流运营玩法，除直发发售之外，支持预约抽签、限量盲盒、碎片合成、藏品转增等模式。管理员可设置藏品发行总量、单人限购数量、发售时间、白名单优先购资格，精准管控发售节奏。创作者入驻模块支持艺术家提交资料申请入驻，审核通过后可以自主提交藏品素材，平台可设置分成比例，吸引创作者入驻，丰富平台文创内容供给。

后台管理板块覆盖用户、藏品、订单、资金、风控、权限管理。管理员可以上架藏品、配置发售计划、审核创作者入驻申请、处理用户申诉；支持订单查询、资金流水查看、提现审核，所有交易记录全程留痕可查。系统支持多级角色权限划分，运营、内容审核、财务账号权限隔离，降低误操作风险。配套数据看板，统计平台访问量、藏品销量、用户增长、成交数据，为运营策略调整提供支撑。

该版本为全开源版本，前后端源码开放，开发者可以自由调整页面 UI、交互逻辑、业务玩法。依托 Uniapp 的灵活性，可拓展拍卖、藏品寄售、积分兑换、社群圈子等功能，也可对接合规联盟链、对象存储、第三方支付服务。私有化部署模式下，平台业务数据自主保管，不依赖第三方 SaaS 平台，便于根据文创项目需求做深度定制改造。
